# Лабораторная работа №5

## Вариант 20

Две динамические библиотеки считают простые числа на отрезке и переводят числа в двоичную или троичную систему.
Первая программа связывается с библиотекой при сборке, вторая загружает библиотеки во время работы.

## Сборка из корня

```bash
cmake -S lab_05 -B build/lab_05
cmake --build build/lab_05
```

## Запуск

```bash
cd build/lab_05
./lab5_linked
# или
./lab5_dynamic
```

Команды ввода: `1 A B` — количество простых чисел на отрезке `[A, B]`,
`2 x` — перевод числа `x`, `0` — переключение библиотеки в `lab5_dynamic`.
Для завершения ввода нажмите Ctrl+D.

На Linux перед сборкой замените в `program2.c` расширения библиотек с `.dylib` на `.so`.
